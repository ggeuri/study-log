### 1) JS 객체 배열로 회원 목록 렌더링
- 좌측 form 입력값을 `{ name, email, job }` 형태의 객체로 생성 후 `memberList` 배열에 `push`.
- `getList()`에서 `memberList`를 `for`문으로 순회하며 `<table>` 태그 문자열을 조립하고, `.innerHTML`로 `.content` 영역에 렌더링.
- `window`의 `load` 이벤트에서 버튼 클릭 핸들러를 등록하여 DOM 로딩 이후에 이벤트를 바인딩하도록 구현.

### 2) Ubuntu 24(ARM) 환경에서 MySQL 8 tarball 수동 설치
- 기존 `mysqld` 프로세스 및 이전 설치 디렉토리 정리 후, `mysql-8.0.44-linux-glibc2.28-aarch64.tar.xz`를 `/opt/mysql8` 위치에 압축 해제.
- `/etc/profile.d/mysql8.sh`에 `MYSQL_HOME=/opt/mysql8` 및 `PATH`를 설정하고 `source`로 적용.
- `/opt/mysql8/data` 디렉토리를 생성하고 권한을 `vboxuser`로 설정한 뒤, `mysqld --initialize`로 1회 초기화 및 root 임시 비밀번호 확인.
- `mysqld_safe`로 서버를 백그라운드 기동하고, `mysql -h localhost -u root -p`로 접속 후 비밀번호 변경.
- `java` 데이터베이스, `servlet@'%'` 계정을 생성하고 권한을 부여한 뒤, `ufw`로 3306 포트를 개방하고 Mac에서 `mysql -h <VM IP> -u servlet -p`로 원격 접속 확인.

### 3) JSP/Servlet 기반 게시판 골격 및 Maven 의존성
- 목록 JSP에 zebra table 템플릿을 적용하고, scriptlet `for`문으로 임시 데이터를 21행 출력하는 구조 작성 (향후 DB 연동 시 `ResultSet` 반복문으로 교체 예정).
- 작성 폼 JSP에서 `id="form1"`인 form을 두고, JS `regist()` 함수에서 `action="/notice/regist"`, `method="post"`를 설정한 뒤 `submit()` 호출.
- `RegistServlet#doPost()`에서 `request.setCharacterEncoding("UTF-8")`과 `response.setContentType("text/html;charset=UTF-8")`를 설정 후, `title`, `writer`, `content` 파라미터 수신 테스트.
- `web.xml`에 `RegistServlet`을 `/notice/regist`에 매핑하고, Maven 프로젝트로 전환하여 `mysql-connector-java:8.0.33` 의존성을 추가.
