1. 쿠키란 ? 브라우저가 저장해놓은 작은 문자열 데이터

2. 쿠키의 형식? key-value의 쌍 첫번째를 쿠키로 보고 뒤부터 옵션으로 본다 document.cookie="name=아담스;age=30"; 이라고하면 document.cookie; 쳤을 때 name=아담스만 나옴 그래서 다 따로 따로 입력해야됨 쿠키에 데이터를 넣을 때는 한꺼번에 못넣는다. (제일 앞에 오는 key-value쌍을 데이터로 인정)

3. 쿠키의 특징? 브라우저를 이용하여 서버에 요청을 보낼때 함께 전송됨(CSRF = Cross Site Request Forgery 해킹문제발생)

4. 쿠키사용예시? 로그인시 아이디 기억하기 체크, 쇼핑몰에서 최근 본 상품 목록, 팝업 다시 보지 않기

5. 쿠키의 옵션 expires 옵션 : 쿠키의 유지 시간을 절대 시간으로 지정하는 옵션(ex 내일 오전 8시 5분까지 유효한 쿠키 지정하려면.. 같을 때) document.cookie="id=apple; expires=Thu, 31 Dec 2026" (형식 이따위임) document.cookie="id=apple; expires=Thu, " +d.toUTCString();
max-age 옵션 : 현재 시점 기준으로 n초동안 유지 60(초)*60(분)*24(시간)*3(일) : 이거 권장함 document.cookie="nickname=zino; max-age=20"; 이런식으로 하면 20초 뒤에 사라짐
이미 설정된 쿠키를 지우는 법 document.cookie="id=; max-age=0"; 이런식으로 키값입력 후 max-age=0 하면 사라짐

쿠키 한번에 넣기 (객체넣기) = 불가 쿠키는 오직 문자열만 넣을 수 있다. 문자열로 바꿔서 넣어야한다. 특정 객체를 문자열로 변환할 때 js 요구하는 객체형태를 유지하며 넣을 수 있어야 함.(JSON) let member={ id:"GR", name :"냠냠", email : "naver" }; document.cookie="member="+member+"; max-age=60"; 꺼낼 떄는? JSON사용해라
